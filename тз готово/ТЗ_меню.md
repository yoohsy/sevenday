# ТЗ / передача: меню (`Assets/Scenes/menu.unity`)

## Сцена и объекты
- Сцена: `Assets/Scenes/menu.unity` (Build Settings index 0, enabled).
- Также включены: `Assets/Scenes/cats.unity`, `Assets/Scenes/SampleScene.unity`.
- Canvas: на `Canvas` добавлен компонент `menu_navigation` (`Assets/scripts/menu_navigation.cs`).
- Панели: `Canvas/main menu`, `Canvas/menu continue`, `Canvas/menu setings` (опечатка в имени сохранена намеренно — скрипт ищет именно это имя).
- Камера: `Main Camera` (orthographic).

## Навигация (реализовано) — `Assets/scripts/menu_navigation.cs`
- `main menu/new game` → `SceneManager.LoadScene("cats")`.
- `main menu/continue` → плавное панорамирование: `menu continue` в `(0,0)`, камера смещается по Y.
- `main menu/setings` → плавное панорамирование: `menu setings` в `(0,0)`, камера смещается по X.
- `menu continue/back`, `menu setings/back` → возврат панелей/камеры в исходное состояние.
- Параметры: `moveDuration = 0.9`, сглаживание `SmoothStep`.
- Скрипт сам находит панели/кнопки по именам (trim, ignore case), вешает listeners и добавляет `button_hover_plate` на все кнопки найденных панелей.

## Hover-подсветка (реализовано) — `Assets/scripts/button_hover_plate.cs`
- Стиль: холодный неон.
- Для каждой кнопки создаётся/переиспользуется дочерний объект-плашка `hover plate` как sibling перед кнопкой (идемпотентно, без дублей при повторном входе в Play).
- Цвета:
  - скрыта: `RGBA(0.25, 0.75, 1, 0)`
  - hover: `RGBA(0.25, 0.75, 1, 0.28)`
  - контур `Outline`: `RGBA(0.2, 0.65, 1, 0.45)`, `effectDistance=(2,-2)`, `useGraphicAlpha=true`
- Масштаб плашки: `1.08` от размера кнопки.
- Копирует sprite/type/preserveAspect/fill/pivot/rect/rotation/scale кнопки; `raycastTarget=false`.
- Плашка следует повороту/масштабу кнопки (`localRotation`/`localScale` копируются).

## Меню продолжения / слоты сохранений
- Кнопки: `slot 1` … `slot 9` (9 шт.) внутри `Canvas/menu continue`.
- Подписи (дочерний `Text` `label` у каждого слота):
  - `slot 1` → `сохранение 2`
  - `slot 2` → `сохранение 3`
  - `slot 3` → `сохранение 4`
  - `slot 4` → `сохранение 5`
  - `slot 5` → `сохранение 6`
  - `slot 6` → `сохранение 7`
  - `slot 7` → `сохранение 8`
  - `slot 8` → `сохранение 9`
  - `slot 9` → `сохранение 10`
- Оформление текста: `LegacyRuntime.ttf`, `fontSize 16`, `Bold`, цвет `RGBA(0.9, 0.97, 1, 1)`, выравнивание по центру, `Horizontal/Vertical Overflow = Overflow`.
- Контур текста: `Outline` `RGBA(0,0,0,0.85)`, `effectDistance=(1,-1)`, `useGraphicAlpha=true`.
- Подписи выровнены по миру (world rotation = 0), читаемые.

## Исправленные проблемы
- **Нечитаемые/перевёрнутые подписи** на слотах: поворот подписей скомпенсирован до `world rotation (0,0,0)`, повышена читаемость (жирный шрифт, контраст, контур).
- **Нерабочие клики `сохранение 4, 8, 9, 10`** (кнопки `slot 3, 7, 8, 9`): у этих слотов был поворот по Y ~167–191°, из-за чего `GraphicRaycaster` не попадал по Graphic кнопки.
  - Исправление: `localEulerAngles.y` обнулён, зеркалирование перенесено в масштаб по X (`localScale.x` со знаком минус), подписи перекомпенсированы (прямые, без зеркала).
  - Проверено: raycast/click проходит по всем 9 слотам, hover-подсветка отображается корректно.

## Важно / что не реализовано
- **Логика сохранения/загрузки по слотам отсутствует.** В проекте нет системы сейвов (`PlayerPrefs`/SaveGame/LoadGame и т.п.), у `slot 1..9` нет обработчиков загрузки конкретного сохранения. Сейчас слоты: корректно отображаются, кликабельны, принимают raycast и подсвечиваются при hover — но действие «загрузить сохранение N» нужно реализовать отдельно (добавить обработчик в `menu_navigation.cs` или повесить `onClick`).
- Имя панели настроек в сцене — `menu setings` (опечатка); `menu_navigation` и сцена используют это имя согласованно.
